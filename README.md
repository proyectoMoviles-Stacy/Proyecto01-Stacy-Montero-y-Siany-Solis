# Proyecto01-Stacy-Montero-y-Siany-Solis
Proyecto de moviles de stacy y siany

Idea de proyecto:
GastroLoop es una aplicación que busca reducir el desperdicio de comida, permitiendo que los restaurantes publiquen a precios más bajos aquellos pedidos que fueron preparados pero que los clientes nunca retiraron. Así otras personas pueden aprovechar esas comidas y los restaurantes no pierden todo lo invertido.
